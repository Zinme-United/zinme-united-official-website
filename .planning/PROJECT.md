# Zinme United Official Website Redesign

## What This Is

A full redesign of the Zinme United official website to look and feel like a professional football club website. The site serves as the public face of Zinme United, an amateur football team, presenting squad info, fixtures & results, club news, and club information in a polished, credible layout that visitors can't distinguish from a professional club's site.

## Core Value

Visitors land on the site and immediately feel they're on a legitimate football club's website — professional presentation that builds credibility for the club.

## Context

- Zinme United is an amateur football team with an existing website that needs a visual overhaul
- The codebase is a Next.js application with TypeScript, Tailwind CSS, and existing data (players, fixtures, news) already present
- Club branding (logo and team colors) already exists and should be used throughout
- The goal is grassroots/amateur club level but with a polished, professional presentation — think a well-run local club, not necessarily Premier League production value
- Current site exists on the `refactor/home-page-ui` branch with a recent home page redesign commit

## Constraints

- **Tech stack**: Next.js + TypeScript + Tailwind CSS — maintain existing stack
- **Data**: Use existing data in the codebase — no new backend work
- **Branding**: Must use existing club logo and team colors
- **Scope**: Full site redesign, not just home page
