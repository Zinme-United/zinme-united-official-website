**In client/src/index.css**, replace the entire file content with:

1. Keep `@import "tailwindcss";` as the first line.

2. Add `@theme` block with ALL tokens (per user decisions and research):
   - Colors: `--color-primary: #003b75`, `--color-primary-light: #0056b3`, `--color-primary-dark: #002a54`, `--color-accent: #ffd700`, `--color-accent-muted: #ffd700cc`, `--color-surface: #ffffff`, `--color-surface-alt: #f8f9fa`, `--color-text: #1a1a2e`, `--color-text-muted: #6b7280`, `--color-text-on-primary: #ffffff`, `--color-text-on-accent: #1a1a2e`
   - Fonts: `--font-heading: "Oswald", sans-serif`, `--font-body: "Inter", sans-serif`
   - Container: `--container-content: 80rem` (1280px per user decision)
   - Radius: `--radius-sm: 0.375rem`, `--radius-md: 0.5rem`, `--radius-lg: 0.75rem`, `--radius-xl: 1rem`, `--radius-card: 0.875rem` (14px midpoint of user's 12-16px)
   - Shadows: `--shadow-card`, `--shadow-card-hover`, `--shadow-elevated` (values from RESEARCH.md code examples)

3. Replace `:root` block to use token references:
   ```css
   :root {
     font-family: var(--font-body);
     line-height: 1.5;
     font-weight: 400;
     color: var(--color-text);
     background-color: var(--color-surface);
     font-synthesis: none;
     text-rendering: optimizeLegibility;
     -webkit-font-smoothing: antialiased;
     -moz-osx-font-smoothing: grayscale;
   }
   ```

4. Add heading typography rules (per user decision -- H1/H2 ALL CAPS, all headings use Oswald):
   ```css
   h1, h2 {
     font-family: var(--font-heading);
     text-transform: uppercase;
     letter-spacing: 0.02em;
   }
   h3, h4, h5, h6 {
     font-family: var(--font-heading);
   }
   ```

5. Update link defaults to use tokens:
   ```css
   a { font-weight: 500; color: var(--color-primary); text-decoration: inherit; }
   a:hover { color: var(--color-primary-light); }
   ```

6. Keep `body { margin: 0; min-height: 100vh; }` as-is.

7. Keep ALL Swiper overrides but replace the hardcoded `#ffd700` with `var(--color-accent)`:
   ```css
   .swiper-pagination-bullet-active {
     opacity: 1 !important;
     background: var(--color-accent) !important;
   }
   ```
   Keep the `rgba(0, 59, 117, 0.6)` in swiper button background as-is -- it is primary at 60% alpha and CSS variable substitution inside rgba() is unnecessarily complex for this override. Add a comment: `/* primary at 60% alpha */`.

Do NOT use `--*: initial` to reset Tailwind defaults. Only add/override specific tokens. The default spacing scale, breakpoints, etc. must remain intact.
