  bg-[#003b75]       -> bg-primary

  bg-[#ffd700]       -> bg-accent

  text-[#1a1a2e]     -> text-text
  bg-[#ffffff]       -> bg-surface
  text-[#6b7280]     -> text-text-muted
  border-[#ffd700]   -> border-accent

For inline styles (style={{ color: "#003b75" }}):
  Replace with className="text-primary" where possible.
  If must stay as inline style, use: style={{ color: "var(--color-primary)" }}

For lucide-react icon color props (color="#003b75"):
  Remove the color prop entirely. Add className="text-primary" instead.
  Lucide icons use currentColor by default and inherit from text color classes.

For SVG/chart configs that pass colors as JS objects (Pitch.tsx):
  Use getComputedStyle approach or keep hardcoded with a comment:
  /* token: --color-primary */ "#003b75"
  This is acceptable for SVG drawing configs that cannot use CSS classes.
